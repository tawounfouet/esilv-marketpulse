# Pre-Lab Diagnostic

## Purpose

This directory documents the pre-lab diagnostic used by the ESILV Python, Git, Linux teaching team.

The diagnostic has three distinct purposes:

```text
questionnaire
=
what is asked before the practical sequence

analysis
=
how the questions relate to the current 18-hour curriculum

interpretation guide
=
how results may inform teaching decisions
```

The diagnostic is not a graded exam and is not part of the Checkpoint A, B or C evidence contract.

## Documents

- `01_PRE_LAB_DIAGNOSTIC_QUESTIONNAIRE.md`: reference transcription of the 39-question teacher-test questionnaire.
- `02_PRE_LAB_DIAGNOSTIC_ANALYSIS.md`: curriculum alignment analysis.
- `03_PRE_LAB_DIAGNOSTIC_INTERPRETATION_GUIDE.md`: operational guide for adapting teaching.

The main principle is:

```text
diagnostic coverage
!=
mandatory course prerequisites
```

The module assumes no previous Linux or Git experience, while some Python fundamentals are expected.

## Public repository warning

This repository may be visible to students.

If the exact questionnaire is used as a live pre-lab diagnostic, publishing the questions before completion can reduce the validity of the diagnostic.

Recommended options:

```text
A. Keep the operational form in a private teacher space until completion.
B. Use this repository copy as an archival/reference version and a distinct live form.
C. Accept that the questions are public and interpret the results accordingly.
```

No answer key is stored here.
